# 0.1.11 — 2026-06-04

## Fixed

- **`wikidata_get_entity`, `wikidata_get_statements`, `wikidata://entity/{id}`** — `entity_not_found` error contract never fired because handlers checked `err.data.statusCode` while `httpErrorFromResponse` stores the HTTP status at `err.data.status`. Updated all three catch sites to use `err.data.status`. ([#9](https://github.com/cyanheads/wikidata-mcp-server/issues/9))
- **`wikidata_sparql_query`** — `truncated` field unconditionally returned `false`, giving agents no signal when Blazegraph silently capped results at 10,000 rows. Now returns `truncated: bindings.length >= 10_000` as an inferred signal; description updated to reflect the heuristic and its limitations. ([#10](https://github.com/cyanheads/wikidata-mcp-server/issues/10))
