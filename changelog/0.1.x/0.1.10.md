# 0.1.10 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.16 → ^0.9.21` — framework adoption:
  - HTTP transport per-request log context fix — per-request logs and traces now carry fresh request + trace/span IDs instead of the frozen boot context.
  - **`fetchWithTimeout`** strips query-string secrets (e.g. `?api_key=`) from error messages and logs.
  - **`withRetry`** fails fast on non-retryable errors; `ctx.fail` auto-populates the `retryable` flag.
- **README** client-config server key renamed from `"wikidata"` to `"wikidata-mcp-server"` (full package name convention) across stdio, npx, and Docker snippets.

## Added

- **`scripts/release-github.ts`** and `release:github` npm script — automates GitHub Release creation with tag notes and `.mcpb` attachment.
- **`scripts/check-skill-versions.ts`** and **`scripts/devcheck.ts`** — skill-version drift detection and unified devcheck runner, synced from framework.
- **`skills/api-mirror`** and **`skills/orchestrations`** — new skills synced from `@cyanheads/mcp-ts-core` 0.9.21.
- 8 updated skills (`add-service`, `add-tool`, `api-canvas`, `api-context`, `api-linter`, `api-utils`, `design-mcp-server`, `release-and-publish`) synced from framework.
