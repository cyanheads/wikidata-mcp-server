# 0.1.12 — 2026-06-12

Framework adoption of `@cyanheads/mcp-ts-core` `^0.10.6` and the maintenance/tooling sync it carries.

## Added

- **`scripts/clean-mcpb.ts`** — post-pack `.mcpb` cleaner wired into the `bundle` script. Runs `mcpb clean` (dev-dependency prune) then strips dependency-shipped agent docs nested under `node_modules/` (`skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.
- **`org.opencontainers.image.version`** Docker label, stamped from the `APP_VERSION` build arg passed at image build time.
- **Container `HEALTHCHECK`** — polls `/healthz` on the configured `MCP_HTTP_PORT`.

## Changed

- **Server identity** — `createApp()` now sets `name`/`title` to `wikidata-mcp-server`; `manifest.json` `display_name` and both plugin `displayName` fields aligned to the unscoped repo name (were `@cyanheads/wikidata-mcp-server`).
- **`wikidata_search_entities` enrichment** — `resultCount` renamed to `shown`; added `cap` (the `limit` in effect) and optional `truncated` (true when results hit the cap), emitted via the framework's `ctx.enrich.truncated()` helper. The Wikidata search API returns no total count, so `truncated` signals "use offset pagination for more."
- **`.mcpbignore`** — root dev-dir patterns anchored with a leading `/` so they no longer also strip nested runtime paths like `node_modules/x/skills/`.
- `@cyanheads/mcp-ts-core` ^0.9.21 → ^0.10.6
- `@biomejs/biome` ^2.4.16 → ^2.5.0
- `@types/node` ^25.9.1 → ^25.9.3
