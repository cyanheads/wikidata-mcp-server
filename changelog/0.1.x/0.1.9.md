# 0.1.9 — 2026-05-30

## Changed

- **`wikidata_search_entities`** — adopts `ctx.enrich`: query echo (`effectiveQuery`), entity type (`searchType`), language, and `resultCount` now surface in a typed `enrichment` block reaching both `structuredContent` and the `content[]` markdown trailer. Empty-result guidance moves to `enrichment.notice` (absent when results present). `no_results` error contract removed — empty results return normally with an enrichment notice instead of a JSON-RPC error.
  - structuredContent renames: `output.query` → `enrichment.effectiveQuery`, `output.type` → `enrichment.searchType`, `output.message` → `enrichment.notice`; `enrichment.resultCount` added.
- **`wikidata_sparql_query`** — adopts `ctx.enrich`: row count and empty-result guidance surface in a typed `enrichment` block. `output.rowCount` removed from the output schema; row count now in `enrichment.totalCount`.
  - structuredContent rename: `output.rowCount` → `enrichment.totalCount`; `enrichment.notice` added.
- **`@cyanheads/mcp-ts-core`** `^0.9.13 → ^0.9.16` — framework adoption for `ctx.enrich` API; picks up 0.9.14 and 0.9.15 improvements (enrichment block, linter rules for enrichment contracts, AGENTS.md support, skills sync for `.agents/skills/`).
