# 0.1.7 — 2026-05-24

## Changed

- **`mcp-ts-core`** ^0.9.7 → ^0.9.9.
- **`check-framework-antipatterns.ts`** — file header clarified to document consumer-side rationale (sync with 0.9.9).
- **`CLAUDE.md`** — framework version reference updated to `^0.9.9`; "Close the loop on issues" core rule added (sync with 0.9.9); `git-wrapup` skill added to skill table.
- **`release-and-publish` skill** — synced to v2.6.
- **`git-wrapup` skill** — added (v1.0, from mcp-ts-core 0.9.8).
- **Code simplification** across `wikidata-rest-service.ts`, `wikidata-sparql-service.ts`, and `resolve-external-id.tool.ts`: `isHtmlResponse` helper deduplicates HTML detection; `Object.fromEntries` replaces label/description loops; SPARQL error extraction collapsed from 3 branches to 1 chained expression; label SERVICE injection simplified to single regex pattern; `extractQid` helper extracted; dedup rewritten with `Map`.

## Fixed

- **`normalizeStatementValue`** — `external-id` and `url` data types were collapsed into `{ type: 'string' }`, losing the type discriminant. They now map to their own `StatementValue` union members (`{ type: 'external-id' }` and `{ type: 'url' }`).
- **Error codes** — `invalid_id`, `invalid_ids`, `not_an_item`, `invalid_property`, `parse_error` contract entries and the SPARQL service changed from `JsonRpcErrorCode.InvalidParams` to `JsonRpcErrorCode.ValidationError` (correct code for caller-supplied bad input).
