# 0.1.14 — 2026-06-20

Framework-maintenance sync for `@cyanheads/mcp-ts-core` `^0.10.9`. No source or behavior changes.

## Added

- **`scripts/check-dependency-specifiers.ts`** — devcheck step rejecting floating dependency specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` dependency sections and `bun.lock`'s `workspaces` map, so a `bun update --latest` writing the literal `latest` dist-tag into the lock can no longer re-resolve a dep past its `package.json` range and ship unnoticed (`cyanheads/mcp-ts-core#246`).

## Changed

- **`devcheck.config.json`** — added `packaging.pluginManifests: true`, opting the `lint-packaging` step into validating the `.claude-plugin` / `.codex-plugin` manifests.
- **`scripts/` + `skills/`** — re-synced from the framework: `lint-packaging.ts` plugin-manifest checks, `devcheck.ts` step wiring, `build-changelog.ts`, `check-framework-antipatterns.ts`, `check-skill-versions.ts`, and the bundled `api-context` / `add-tool` / `polish-docs-meta` skill docs.
- `@cyanheads/mcp-ts-core` ^0.10.6 → ^0.10.9
- `@types/node` ^25.9.3 → ^26.0.0
