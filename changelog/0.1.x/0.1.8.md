# 0.1.8 — 2026-05-28

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.9 → ^0.9.13` — framework adoption picks up:
  - **`MCP_HTTP_MAX_BODY_BYTES`** — configurable inbound request-body cap (default 1 MiB); oversized requests rejected with `413` before the SDK parses the body.
  - **HTTP session-init gate** — stateful HTTP mode now rejects non-`initialize` requests without an `Mcp-Session-Id` header with HTTP `400`.
  - **Quieter expected client errors** — `401`, `403`, `400`, and `404` responses now logged at `warning` instead of running through the full error pipeline with stack traces.
  - **`GET /mcp` keywords** — `package.json` `keywords` now surfaced on the HTTP status endpoint alongside name, version, and description.
- **`@biomejs/biome`** `^2.4.15 → ^2.4.16`
