# 0.1.18 — 2026-08-22

## Changed

- **MCP protocol surface** — upgrades `@cyanheads/mcp-ts-core` from `^0.10.14` to `^0.12.3`, adding MCP 2026-07-28 support, JSON Schema 2020-12 where appropriate, advertised error envelopes in tool outputs, and rejection of undeclared root tool input keys instead of silently stripping them.
- **HTTP session mode** — explicitly selects stateless serving across the Docker image, `.env.example`, and README configuration reference.
- **Framework integration** — adopts direct request `Context` passing, canonical `data.status`, Bun 1.4 tooling, TypeScript 7, current project scripts and skills, and the framework community-health files.

## Fixed

- **`wikidata_get_labels` text content** — preserves descriptions in each requested language while retaining sampled labels from additional languages.
- **`wikidata_get_statements` text content** — includes up to three statement references and renders external IDs and URLs alongside other values.
- **SPARQL cancellation** — preserves caller-initiated cancellation while classifying the server's own query deadline as `Timeout`.
