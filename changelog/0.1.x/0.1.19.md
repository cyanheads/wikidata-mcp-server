# 0.1.19 — 2026-09-20

## Changed

- **Argument rejections** classify as `InvalidParams` (`-32602`) instead of `ValidationError`, with a synthesized `Recovery:` hint and a `(reason …)` tail appended to the error text.
- **Mid-call disconnects** classify as `RequestCancelled` (`-32011`) instead of an internal error.
- **Tool arguments** pass a pre-validation step that drops client-added root keys and rewrites case-style key variants before schema validation.
- **Upstream errors** no longer place the REST or SPARQL request URL on client-facing `error.data`.
- **`src/index.ts`** declares `sessionMode: 'stateless'` explicitly rather than leaving it to `MCP_SESSION_MODE`.
- **Bun engines floor** raised to `>=1.4.0`.
- **Development tooling** — skills relocated `skills/` → `framework-skills/` (a plugin install no longer hands them to the installing agent), and scaffolded scripts, GitHub issue templates, and `.claude-plugin/plugin.json` synced to the current mcp-ts-core scaffold.
