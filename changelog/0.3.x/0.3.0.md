# 0.3.0 — 2026-10-28

## Added

- Add the `wikidata-guide` skill resource for entity disambiguation, statement evidence, external-ID joins, and SPARQL workflows.
- **Agent Plugins 1.0.0** root manifests support plugin installation alongside the existing Claude Code and Codex overlays.

## Changed

- **Skill delivery** includes the guide and SPARQL reference in npm, Docker, plugins, and MCPB; MCP serves `skill://wikidata-guide/SKILL.md` and the skill file template.
- **Search enrichment** renders `effectiveQuery`, `searchType`, and `language` trailers as code literals through framework 0.13.18.
- **Development tooling** syncs framework skills, packaging validation, and bug-report environment tables; dependency minimum release age is one day.
- **README** condenses setup into hosted and local commands with Docker and source-build instructions under Running the server.

## Fixed

- **HTTP request signals** no longer accumulate under sustained traffic through the framework fix in [cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786).
- **MCPB cleanup** removes build-only files and node-gyp output while preserving SDK runtime skill modules, with regression coverage ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)); skill validation stays out of runtime bundle imports ([cyanheads/mcp-ts-core#797](https://github.com/cyanheads/mcp-ts-core/issues/797)).
- **Statement guidance** describes preferred rank as favored statements and directs callers to qualifiers and references for temporal scope and evidence.
- **Docker image title** uses the display name `wikidata-mcp-server`.
