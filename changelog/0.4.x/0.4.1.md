# 0.4.1 — 2026-11-21

## Added

- **Missing selectors:** `wikidata_get_statements` includes zero totals and a notice for absent requested properties. `wikidata_get_sitelinks` lists missing requested site codes in `notFound`, determined before filtering to Wikipedia editions. ([#64](https://github.com/cyanheads/wikidata-mcp-server/issues/64))

## Changed

- **`wikidata-guide` 1.1 → 1.2** distinguishes server-injected namespaces from Query Service defaults and adds a bounded, class-scoped name search recipe. ([#65](https://github.com/cyanheads/wikidata-mcp-server/issues/65))

## Fixed

- **Statement values** preserve calendar models and globes on main values, qualifiers, and reference parts. `wikidata_get_statements` and `wikidata_get_entity` show the identifiers in Markdown alongside the stored dates and coordinates. ([#59](https://github.com/cyanheads/wikidata-mcp-server/issues/59))
- **Merged entity IDs** return the canonical ID and `redirectedFrom` from the entity, statements, and sitelinks tools. Statement property selections survive redirects that drop the upstream filter. ([#60](https://github.com/cyanheads/wikidata-mcp-server/issues/60))
- **`wikidata://entity/{id}`** uses the canonical ID in the resource heading and Wikidata link, and displays the requested ID when it redirects.
- **`wikidata_resolve_external_id`** resolves PMC-prefixed PMCIDs, ROR URLs, spaced ISNIs, and arXiv labels or abstract URLs to the same matches as their stored forms. ([#61](https://github.com/cyanheads/wikidata-mcp-server/issues/61))
- **Unrecognized term languages** are reported by `wikidata_get_labels` alongside valid results. `wikidata_get_statements` preserves statements with `labelsResolved: false` and a notice when Wikidata rejects the requested language. ([#62](https://github.com/cyanheads/wikidata-mcp-server/issues/62))
- **`wikidata_get_sitelinks`** excludes Abstract Wikipedia under `wikis_only` and lists it outside the edition group in unfiltered Markdown. ([#63](https://github.com/cyanheads/wikidata-mcp-server/issues/63))
